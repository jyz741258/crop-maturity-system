# 叶用经济作物成熟度判别系统

## 系统简介

本系统基于图像处理技术，通过分析叶片的颜色特征、纹理特征和形态特征，自动判别叶用经济作物的成熟度阶段。系统支持单张图片分析和批量文件夹处理，适用于茶叶、烟叶、桑叶等叶用经济作物的成熟度监测。

## 系统功能

- **单张图片分析**：上传单张作物叶片照片，实时分析并返回成熟度结果
- **批量文件夹处理**：选择包含多张图片的文件夹，批量分析并生成统计报告
- **可视化结果展示**：展示成熟度、置信度、绿色占比、纹理特征等详细信息
- **采收建议**：根据成熟度提供最佳的采收时机建议

## 技术架构

- **后端**：Python Flask框架，提供RESTful API
- **图像处理**：OpenCV、scikit-image
- **特征提取**：颜色特征（HSV颜色空间）、纹理特征（GLCM）、形态特征（轮廓分析）
- **前端**：HTML5、CSS3、JavaScript，响应式设计
